# docs 索引

nasne の録画保護(DTCP-IP と保存時の暗号化)に関する解析記録。本文書が全体の索引で、各文書の冒頭にも対象と状態の要約がある。

> 記録の方針: 要約で済ませず、根拠・数値・手順・未確定事項まで書く。鍵の値そのものと個体を特定できる値は書かない(存在・形式・所在・導出手順の構造まで)。作法の詳細は [AGENTS.md](../AGENTS.md)。
